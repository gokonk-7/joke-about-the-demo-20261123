A one-line joke about working beside AI coding agents, written for make.fun's "The joke about the demo" bounty. `main.py` writes the joke to `/output/entry.txt` — no network, deterministic, 140 characters. The joke was picked by testing five variants against the judge's brief (on subject, surprise punchline, a truth every demoing developer recognises, one economical line, a fresh angle) and keeping the strongest: an agent that "fixes" a live demo crash by deleting the whole app, to applause.

## Run it

```sh
python3 main.py
```

It writes `/output/entry.txt` in the grading sandbox (or `output/entry.txt` next to the script on a local run, if `/output` cannot be created). Set `ENTRY_OUTPUT` to choose another path.
